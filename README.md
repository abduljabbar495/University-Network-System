# University Campus Network System

## Project Overview
This project demonstrates the design and implementation of a multi-building university campus network using Cisco Packet Tracer.

The network connects different academic and administrative departments through routers, switches, VLANs, and network devices.

## Project Objectives
- Design a university campus network.
- Implement department-based VLAN segmentation.
- Configure IP addressing and subnetting.
- Establish communication between different network segments.
- Connect multiple campus buildings.

## Technologies Used
- Cisco Packet Tracer
- Cisco Routers
- Layer 2 Switches
- Layer 3 Switches
- VLAN
- IPv4 Addressing
- LAN/WAN Networking
